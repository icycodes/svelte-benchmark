### Optimistic UI via overridable `$derived` (Svelte 5.25+)

```ts
class PostState {
    serverLikes: number;
    likes = $derived(this.serverLikes);   // overridable derived
    constructor(initialLikes: number) { this.serverLikes = initialLikes; }
}
```

Inside `handleLike`:
1. `state.likes += 1` — immediate optimistic increment (no `await`)
2. `await fetch(...)` — sends the POST request
3. On success → `state.likes = body.likes` (reconcile with server truth)
4. On failure → `state.likes -= 1` (rollback)

This uses Svelte 5.25's ability to reassign a `$derived` variable directly — no separate `$state` mirror + `$effect` needed.
