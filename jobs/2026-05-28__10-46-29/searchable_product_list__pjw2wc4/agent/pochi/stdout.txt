## Key implementation details

**`/api/products`** — returns the fixed 6-product array (Apple iPhone, Banana Phone, Cherry Tablet, Pear Laptop, Grape Watch, Melon Speaker).

**`/products` load function** — reads `url.searchParams.get('q')`, calls `fetch('/api/products')` (SvelteKit inlines the response into SSR HTML to avoid a second request on hydration), then case-insensitively filters and returns `{ q, products }`.

**`+page.svelte`** — uses all required Svelte 5 runes:
- `$props()` — receives `data` from load
- `$state(data.q)` — tracks live input value
- `$effect()` (×2) — one syncs `searchValue` back to `data.q` on navigation; one debounces `goto(...)` calls by 200 ms
- `$derived()` — computes visible product count

**URL sync** — `goto(\`/products${params}\`, { replaceState: true, keepFocus: true })` keeps focus and rewrites history without adding entries.

**Progressive enhancement** — search input lives inside `<form method="get" action="/products">` so it works without JavaScript.
