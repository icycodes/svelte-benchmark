## Key implementation details

### `+page.server.js`
- **`load()`** — reads `todos.json` from disk and returns the array to the page.
- **`add` action** — validates the `text` field, appends a new todo (UUID id, `completed: false`), writes JSON.
- **`toggle` action** — flips `todo.completed` for the submitted `id`, writes JSON.
- **`delete` action** — filters out the todo with the submitted `id`, writes JSON.
- Data file path is resolved via `import.meta.url` → stable regardless of working directory.

### `+page.svelte` (Svelte 5 runes)
- `$props()` — receives `data` (server load result) and `form` (action result).
- `$derived(data.todos)` — reactive list that auto-updates after every action.
- `$derived(todos.filter(…).length)` — remaining count, computed reactively.
- `$state('')` — controlled input for the add form.
- `use:enhance` on all three forms for progressive enhancement (zero-JS fallback via plain HTML POSTs also works).
